# 📖 Overview

AI Smart Home IoT System is a modern home automation platform that combines IoT devices with Artificial Intelligence to create a secure, energy-efficient, and intelligent smart home environment.

The platform enables users to remotely monitor and control home appliances, automate routines, receive real-time alerts, analyze energy consumption, and interact with an AI assistant powered by Google Gemini.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Kumaran-gugan/AI-Smart-Home-IoT-System.git
```

Navigate to the project

```bash
cd AI-Smart-Home-IoT-System
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
